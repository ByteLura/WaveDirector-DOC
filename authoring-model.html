Authoring Model: Archetypes, Definitions, Sets

Expanded from the shipped Documentation~/ApiReference.md.

Everything you author is a ScriptableObject. No wave data lives in code constants.

WaveArchetype — an enemy kind

FieldMeaning
IdStable string id, unique per roster
DisplayNameThe name shown in editor surfaces
PrefabThe enemy prefab the spawner creates
ThreatCostWhat one of these costs a wave budget (1 or more)
MinWaveThe first wave it may appear in, counted from 1
WeightIts composition weight in budget-mode casting
PrewarmCountHow many a prewarm-capable spawner prepares on start

Create archetypes from Assets > Create > ByteLura > WaveDirector > Enemy Archetype, one per enemy kind, and give each a threat cost that reflects how threatening it actually is — the budget system is only as honest as the costs you set.

WaveDefinition — one wave inside a set

FieldMeaning
KindStandard or Boss
ModeBudget (composed) or Explicit (authored list)
BudgetThe wave's base budget in budget mode
BudgetOverrideAbove 0, this hard number wins over the difficulty curve, unscaled
Entries + ShuffleExplicitThe authored entry list for Explicit mode, optionally shuffled with the wave's seed
BossArchetypeThe boss for Boss-kind waves
SpawnIntervalSeconds between spawns (before difficulty compression)
MaxAliveAlive cap for the wave; 0 means no cap
MaxSpawnsCaps budget-mode casts; Explicit mode is authored exactly and never truncated
IntermissionAfterPause after this wave; below 0 means the set default
TimelineSecondsTimeline block width hint only

Wave indices in code are 0-based; MinWave eligibility counts from 1.

WaveSet — the run

A wave set holds the roster (Archetypes), the ordered Waves, the Difficulty settings, the DefaultIntermission, the Seed, the RandomizeSeedOnStart opt-in toggle, and AfterLastWave — what happens when the authored waves end: Stop, Loop, or Endless (page 06).

The set answers two questions for any absolute wave index: DefinitionForWave(index) maps the index through the end behaviour, and EffectiveBudget(index) returns the budget that actually casts there — the definition's scaled budget, or its override when one is set.

How the pieces fit

Roster first (what exists, and what it costs), waves second (how much each wave may spend, and how it is paced), set last (the curve, the seed, and what happens at the end). Page 05 covers how a budget becomes a cast.
