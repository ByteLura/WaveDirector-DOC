API Summary

A summary of the shipped Documentation~/ApiReference.md; that page is the full reference. Namespace: ByteLura.WaveDirector. Everything below is public API; the director's internals are not part of the contract.

Authoring data

  • WaveArchetype (ScriptableObject) — Id, DisplayName, Prefab, ThreatCost (1 or more), MinWave (first eligible wave, from 1), Weight, PrewarmCount.
  • WaveDefinition — Kind (Standard/Boss), Mode (Budget/Explicit), Budget, BudgetOverride (above 0 wins over the curve, unscaled), Entries + ShuffleExplicit, BossArchetype, SpawnInterval, MaxAlive (0 = no cap), MaxSpawns (budget mode only; Explicit is authored exactly), IntermissionAfter (below 0 = set default), TimelineSeconds (block width only).
  • DifficultySettings — Mode (Flat/Linear/Exponential), BaseMultiplier, GrowthPerWave, IntervalScalePerWave. Budgets scale as floor(base × multiplier); intervals compress toward a 0.05 s floor.
  • WaveSet (ScriptableObject) — Archetypes, Waves, Difficulty, DefaultIntermission, Seed, RandomizeSeedOnStart, AfterLastWave (Stop/Loop/Endless). DefinitionForWave(index) and EffectiveBudget(index) answer for any absolute index. Code indices are 0-based.

Composition

WaveComposer.Compose(set, waveIndex, seed) returns a CompositionResult: Queue (spawn order; boss first on boss waves), TotalCost, UnspentBudget, and flags HitSpawnCap, BossClamped, NoAffordableArchetype. Deterministic, with per-wave streams — page 09.

The engine

WaveEngine(set, sink, points) is a plain C# class — no scene required. Drive it with Tick(deltaTime).

  • Controls: StartRun(seed), Pause(), Resume(), Stop() (despawns the field), SkipToWave(index).
  • State: State (Idle/Intermission/Spawning/Completed), IsPaused, CurrentWaveIndex, AliveCount, QueueRemaining, TotalSpawned.
  • Events: WaveStarted, WaveCompleted, IntermissionStarted, AllWavesCompleted, EnemySpawned(archetype, handle), WarningRaised (plain-language, designer-facing).
  • PreviewComposition(index, seed) composes without running, through the same code path the engine uses.

Spawning

The full sink contract, the alive rule, and the three shipped paths are page 07. Per-director choice: WaveDirectorBehaviour.SinkMode — Auto (registered sink, then pooled bridge, then fallback), Pooled, or Instantiate. On start, a prewarm-capable sink receives each archetype's PrewarmCount once, before the first spawn.

Spawn points

SpawnPointGroup collects points deterministically — an explicit list, or child transforms in hierarchy order — with group defaults for Weight (0 or below disables a point), CooldownSeconds, and per-point MaxAlive. A director with no usable points anywhere spawns at its own transform (one implicit point).

The scene driver

WaveDirectorBehaviour — assign Set, choose the sink Mode, StartOnPlay. Transport: StartWaves(), PauseWaves(), ResumeWaves(), StopWaves(), SkipToWave(index). Display: CurrentWave (1-based), AliveCount, QueueRemaining, State, IsRunning, and the Engine itself. Engine events are mirrored as C# events and as UnityEvents (OnWaveStarted, OnWaveCompleted, OnAllWavesCompleted) for inspector wiring. Its custom inspector shows transport buttons and live stats in Play Mode.

Networking hooks (hooks only — no transport ships)

  • WaveEngine.HasSpawnAuthority — when false, the engine never asks its sink to spawn; non-authority replicas are driven by snapshots.
  • CaptureSnapshot() / ApplySnapshot(snapshot) — a WaveSnapshot carries wave index, state, state elapsed time, seed, and total spawned. Because composition is deterministic, applying a snapshot reproduces the authority's exact queue for that wave. A snapshot aligns wave and phase; it does not reconstruct individual already-spawned enemies — apply at wave start when that matters. See page 12.
