Quick Start

Expanded from the shipped Documentation~/QuickStart.md.

From import to a directed wave, following only the product's own surfaces.

1. Open the home window

Tools/ByteLura/WaveDirector Pro. On first open, the welcome block shows the product name, the outcome line, the version line, and four quick actions: Open the First Night Demo, Verify Install, Documentation, and Support. Run Verify Install first — it checks the package and test-casts a wave in memory, without touching your scene.

2. Run the demo

Click Open the First Night Demo — it imports the sample if needed and opens the demo scene — then press Play. Marchers stream toward the core; the HUD reads the wave, the alive count, and how many are still to cast. Three waves: a budget ramp, a mixed push, then a boss wave. The full sample guide is page 10.

3. Direct something

Stop. In the home window, click Open in Wave Timeline. Select wave 2, raise its Budget, and press Play again. A larger, differently-cast wave 2 arrives. Same seed, same waves — until you change the numbers. That contrast is the product: waves are composed to budgets you set, not lists you typed.

4. Put a director in your game

In your scene, use Add Wave Director to Scene from the home window. It creates a WaveDirector object and a Spawn Points group with four starter points in a loose ring — drag those points into your level.

Create a wave set (Create a Wave Set in the home window), add your enemy prefabs as archetypes (Assets > Create > ByteLura > WaveDirector > Enemy Archetype) with a threat cost each, author two or three waves, and assign the set to the director. The director starts on Play by default.

When something looks wrong

The timeline shows a warning strip for authoring problems (a budget that buys nothing, a boss wave with no boss). During Play, the director logs plain-language warnings for runtime conditions (a boss that costs more than its wave's budget). Each message names the fix. See page 13.
