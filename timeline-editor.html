The Timeline Editor

Expanded from the product specification's window description and the shipped documentation.

Open it from the home window (Open in Wave Timeline) or directly at Tools/ByteLura/WaveDirector Pro/Wave Timeline.

Layout

  1. Toolbar — a wave set field; a seed field (it edits the set's seed); Add Wave; and Simulate All, which composes every wave with the current seed and reports each queue's size and spend in the status line — the balance check you run before Play, not after.
  2. Timeline strip — one block per wave, width proportional to the wave's timeline hint, intermissions shown as gaps. Boss waves carry a "Boss" tag. Blocks show the wave number, its kind, and its effective budget (after difficulty scaling). Clicking a block selects it; the strip scrolls horizontally rather than shrinking blocks below a legible minimum width.
  3. Wave inspector — the selected wave's fields in plain language: Name, Kind, Composition (Budget or Explicit), Budget with the computed effective budget after difficulty shown beside it, spawn interval, max alive, max spawns, intermission after, the boss archetype for boss waves, and the entries list for Explicit mode.
  4. Validation strip — validator warnings for the whole set, in wave order. Silent when the set is clean.
  5. Footer totals — total timeline length, total effective budget across all waves, and roster size.

What the validator catches

Warnings are written in plain language: what happened, and the one action that fixes it. The validator flags, at authoring time:

  • A wave whose budget buys nothing (the cheapest archetype costs more than the wave can spend).
  • A boss wave with no boss archetype assigned.
  • A roster entry no wave's effective budget can ever afford — a dead archetype that would never be cast.

The numbers the window shows come from the same data pass the validator and the totals use — the window never computes a different answer from the model behind it.

The working loop

Select a wave, change a number, run Simulate All, read the new cast size and spend, then Play. The first-run version of that loop — raise wave 2's budget in the First Night set and watch a different army arrive — is the product's first success, and it is two clicks deep from the home window. With no set selected, the timeline shows a set field and the same two starting actions as the home window (Create a Wave Set, Open the First Night Demo) — never an empty grid.
