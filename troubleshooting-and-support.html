Troubleshooting and Support

Every entry below names a condition the product itself reports, and the fix its message points to. WaveDirector Pro's warnings are written to state what happened and the one action that fixes it — start from the message, not from a search engine.

Authoring-time warnings (timeline validation strip)

  • "Wave N's budget buys nothing — the cheapest archetype costs more." Raise that wave's budget (or its override), or lower an archetype's threat cost. Until then the wave casts an empty queue and completes immediately at runtime.
  • A boss wave with no boss archetype. Assign a BossArchetype on the boss-kind wave definition.
  • An archetype no wave can ever afford. A roster entry whose cost exceeds every wave's effective budget is never cast. Lower its cost, raise a budget, or remove the entry.

Runtime warnings (director log / WarningRaised event)

  • Boss clamped. The boss cost more than its wave's budget. The boss still spawned — alone, with no escorts — and the reported total is the true over-budget figure. Raise the boss wave's budget if you want the escort fill back.
  • No affordable archetype. The wave's queue was empty, so the wave completed immediately instead of hanging. Same fix as the authoring warning above.
  • A spawner refusing spawns. The engine waits an interval and retries — the spawn is not dropped. If it persists, check the sink: a pool at its cap, or a custom sink returning false.

Behaviour that looks wrong but is the contract

  • A wave will not complete. A wave completes only when its queue is empty AND nothing it spawned is alive. Enemies count as cleared when destroyed or deactivated; an enemy that is merely hidden, disabled in logic but still active, or parked alive off-screen still holds the wave.
  • Spawning paused mid-wave. The alive cap (wave-level or per-point) is reached, or the eligible points are resting on cooldown. It resumes on its own as things clear.
  • The cast changed after you edited a later wave. It should not have — per-wave streams isolate earlier waves (page 09). If you reordered the waves themselves, the definitions moved to new indices, and that is authoring, not drift.
  • A fresh rig spawns from one point. With no spawn-point groups anywhere, the director uses one implicit point at its own transform. Arrange a SpawnPointGroup and it takes over.
  • The demo scene content is missing. Run Open the First Night Demo again — it rebuilds the generated content with the shipped builder and says so in the status line — or run Tools/ByteLura/WaveDirector Pro/Build First Night Demo.

Setup checks

Run Verify Install from the home window before anything else: it confirms the assemblies loaded and test-casts a wave in memory, reporting one plain-language line per check. Running Add Wave Director to Scene twice is safe — it never creates a second rig.

Support

Support: bytelura@gmail.com. When you write, include your Unity version, the wave set and seed involved, and the exact warning text — with a set and a seed, the cast you saw is the cast that can be reproduced.
