Sample Guide: First Night

Expanded from the shipped sample README (Samples~/Demo/README.md).

What the sample is

First Night is the bundled demo: a three-wave night on a ground plaza. Marchers stream from four spawn points toward a core; the core's pulse downs the oldest marcher every 2.5 seconds; arrivals cost the core health. The HUD (plain uGUI Text, no extra package needed) shows the wave, how many are alive, how many are still to cast, and the core's health. If the core stands when the last wave clears, the night holds.

Open it with Open the First Night Demo in the home window — the action imports the sample if needed and opens the scene; if the generated scene content is ever missing, the action rebuilds it with the shipped sample builder and says so in the status line.

The three waves

  1. Wave 1 — First Contact. Casts to a budget of 120.
  2. Wave 2 — The Push. Casts to 220, with faster runners mixed in.
  3. Wave 3 — Boss Night. The boss goes first, escorts fill after — the boss-wave rule from page 06, visible in play. The wave does not complete while the boss is alive.

The roster is Grunt and Runner; the Boss archetype is referenced by wave 3 only. Every balance number lives in the generated FirstNightWaves wave set asset — open it and the whole night is numbers you can change.

The one-minute lesson

Stop. Open Tools/ByteLura/WaveDirector Pro/Wave Timeline, select FirstNightWaves, and raise wave 2's budget. Press Play again. A visibly larger, differently-cast wave 2 arrives — because composition, not a spawn list, drives the run. That single edit is the whole product.

How it is put together

  • The scene's WaveDirector object carries the director; Spawn Points carries the four points; the Core, referee, and HUD are sample-only scripts.
  • Sample scripts use only the public API and live in their own assembly, referencing the Runtime only — the sample is also a worked example of integrating the director from outside.
  • The marcher script is deliberately minimal demo content — it walks and arrives. It is not an enemy system. Your game replaces it with real enemies; the director does not care, because "cleared" means destroyed or deactivated, which is what spawning and killing already do.

Rebuilding the demo content

The scene, prefabs, and wave set are generated assets, built by the sample's scene builder inside Unity. If they are ever missing, run Tools/ByteLura/WaveDirector Pro/Build First Night Demo — it rebuilds them in place.
